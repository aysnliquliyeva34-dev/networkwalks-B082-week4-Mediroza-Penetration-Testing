# Week 4 – Mediroza General Hospital Penetration Testing Project

This repository contains my Week 4 cybersecurity project completed as part of the **Networkwalks Cybersecurity Program – Batch B082**.

## Project Overview

The project involved an authorized **black-box penetration testing assessment** against the Mediroza General Hospital training environment.

The assessment covered:

- Reconnaissance and exposed resource discovery
- Patient portal and authentication security assessment
- Access-control testing
- Analysis of protected PDF documents
- Password-security assessment
- Investigation of sensitive data exposure
- Risk analysis and remediation recommendations
- Preparation of a professional penetration testing report
